# 海外の空中写真・古地図と英語版の公開 仕様・設計

- 作成: 2026-10-27
- 承認: オーナー（2026-10-27）「プロトタイプと記載しているので、公開してもよい」。英語版の URL は `/en/` の案、フランスの古地図は (B) 確認できるまで外す
- もとにした試作: `overseas-test.html`（[設計](../design/overseas_prototype.md)）・`top-test.html`（[設計](../design/top_test_prototype.md)）

## 1. 目的・背景

- 試作で確かめた「海外の空中写真・古地図」を、**試作の表示を残したまま**公開し、トップから入れるようにする
- 外国の人に見つけてもらえるよう、**英語のページを別の URL（`/en/`）**で出す。試作の「同じ URL でブラウザの言葉で自動切り替え」は、
  検索エンジンに英語のページとして読まれ日本語の順位を落とすおそれがあるのでやめる（[試作トップの設計](../design/top_test_prototype.md) §4・R4）

## 2. 機能一覧

### 言葉の切り替え

- 言葉は **ページごとに決まっている**。HTML に静的に書いた `<html lang>` を JS が読む（`file://` では場所のパスが `/en/` で始まらないので、パスでは判定しない。R3）。
  ブラウザの言葉では切り替えない（自動で別の URL へ飛ばすこともしない）
- 切り替えボタンは、もう一方の言葉の同じページへの**リンク**（`hreflang`・`lang` 付き）。海外のページでは、今の場所・ズーム・種類・年をアドレスの `#` 以降に入れて引き継ぐ
  （例 `../en/overseas/#15/47.37690/8.54170/map/1900`）。**地図を動かす・種類や年を変えるたびに**、切り替えリンクの `href` と自分のアドレスの `#`（`replaceState`）を書き直す（R6）
- 新しく書くリンクと画像は**相対パス**（`../en/`・`overseas/`・`../images/…`）。`/en/` 配下は1階層深いので、試作の `images/…`・`/map/` などはすべて書き直す（R2）。
  公開サイトのリンクはフォルダの形（`../en/`）のまま。`file://` ではフォルダに `index.html` が補われないので、E2E はリンクを押さず、
  **href を解決して（フォルダなら `index.html` を足して）ファイルが実在するか**を確かめる（R1）

### 検索エンジン向け（各ページの `<head>`）

| 項目 | 内容 |
|---|---|
| `robots` | `index,follow`（試作の `noindex` を外す） |
| canonical | 自分の URL |
| hreflang | `ja`・`en`・`x-default`（日本語）を、日英の組で互いに書く |
| title・description・OGP | 言葉ごとに書く。英語トップは `og:locale=en_US` |
| 構造化データ | 英語トップに英語の WebSite・WebApplication・FAQPage（画面の英語の質問と一致させる）。日本語トップは今のまま |
| `sitemap.xml` | `/overseas/`・`/en/`・`/en/overseas/` を足す |

### フランスの古地図

カッシーニ図・参謀本部図は利用条件を一次資料で確かめられていない（[調査 7.1](overseas_sources_research.md)）。**確認できるまで外す**。

## 3. 非機能要件

| 項目 | 内容 |
|---|---|
| 公開サイトへの影響 | 日本語トップを変える（入口・English・ヘッダー）。`/map/` は変えない |
| 性能 | 海外のページは JS・CSS を `overseas/overseas.js`・`overseas.css` に分け、日英の2つの HTML から読む（同じ処理を2つ持たない） |
| 可用性 | 配信元の一部の失敗は今までどおりお知らせを出さない。全部の失敗だけ知らせる |
| セキュリティ | 外部へ送るものは無い。`#` の値は数値・決まった文字だけを受け付ける |
| アクセシビリティ | `<html lang>` は静的に正しく書く（JS を待たない）。切り替えのリンクには `hreflang` と `lang` を付ける |

## 4. 制約・前提

- GitHub Pages はページごとの HTTP 転送ができないので、試作のアドレスは **小さな HTML（`meta refresh` と JavaScript）で転送**し、`noindex` と canonical を付ける
- 日本語トップのヘッダーに「English」を足すと、スマホ（360px）で入りきらない（[試作トップのレビュー R1](../design/top_test_prototype.md)）。
  試作トップと同じく、**760px 以下ではヘッダーの「地図をひらく」を外す**（本文のすぐ下に同じボタンがある）
- 海外のページの日英の HTML は、**地図と操作の部分（要素と id）は同じ**にする。見出し・短い説明・切り替えリンクは言葉ごとに `<body>` に静的に書く
  （JS を動かさないクローラーにも中身と切り替え先が見えるように。R4）。E2E で両方の id の組が同じことを確かめる

## 6. 異常系

| 場面 | 対処 |
|---|---|
| `#` の値がおかしい（`#abc`・範囲外の緯度・知らない種類） | 無視して初期表示（東京・最新） |
| `#` の位置は正しいが、種類や年がその場所に無い（例: 外したフランスの古地図 `#…/48.85/2.35/map/1880`） | 位置とズームは残し、空中写真のいちばん近い年を出す（R5） |
| 試作のアドレスに `?lang=en` 付きで来た | 英語のページへ転送。それ以外は日本語へ |
| JavaScript が動かない（転送ページ） | `meta refresh` で転送する。本文に新しい URL へのリンクも置く |
| JavaScript が動かない（英語トップ） | 英語の文章はそのまま読める（英語だけの HTML なので、試作のような日英の隠し分けは無い） |

## 7. 仮想レビュー（実装前・2026-10-27）

レビュワー: A 海外向け SEO・B 多言語化・C 静的サイトの設計・D 地図の UX。

| ID | 場所 | どう壊れるか | 重大度 | 対応 |
|---|---|---|---|---|
| R1 | 「file:// でも同じように動く」 | `file://` ではフォルダのリンクに `index.html` が補われず、E2E で押すと壊れる | 中 | 一文を消し、E2E は href を解決してファイルの実在を確かめる |
| R2 | 試作から `/en/` に写すとき | `images/…` が `/en/images/…` になり 404。絶対パスは `file://` で切れる | 高 | `/en/` 配下のパスを1階層深い前提で書き直す。E2E で全ページのローカルの `src`・`href` の実在を確かめる |
| R3 | 「URL で決まる」 | `file://` ではパスが `/en/` で始まらず、英語のページが日本語で描かれる | 中 | 静的な `<html lang>` から読む |
| R4 | 「`<body>` は同じ」 | 文字が全部 JS 製で、JS を動かさないクローラーには `/en/overseas/` が空。切り替えリンクも見えない | 中 | 見出し・説明・切り替えリンクは言葉ごとに静的に書く |
| R5 | `#` の異常系 | 外したフランスの古地図の共有リンクで、真っ白か東京へ飛ぶ | 中 | 位置は残し、空中写真の近い年 |
| R6 | `#` の引き継ぎ | リンクを読み込み時だけ作ると、動かしてから切り替えると最初の場所に戻る | 低 | 動かす・変えるたびに書き直す。E2E に「動かしてから切り替える」 |

判定: R1〜R6 を反映する条件で4人とも LGTM。

## 8. 仮想レビュー（実装後・動く画面を通しで操作。2026-10-27）

同じ4人が、日英のページを 360×640・390×844・1280×800 で最初から操作した（チューリッヒ→古地図→年を戻す→地図を動かす→English→日本語）。R1〜R6 は直っていることを確かめた。

| ID | 場所 | どう壊れるか | 重大度 | 対応 |
|---|---|---|---|---|
| P1 | `#` の書き出し | ズーム1まで引く・地図を横に1周させると、読み直せない `#`（ズーム1・経度 499）を書き、切り替えや共有で初期表示に戻る。1周すると国も「対象外」になる | 低 | 地図の最小ズームを2にし、`worldCopyJump` と `wrapLatLng` で経度を -180〜180 に保つ |

| P3 | 英語のページの題名 | JS が HTML の題名を短い文で上書きし、`og:title` と食い違う | 低 | JS の題名を HTML と同じ文にした |
