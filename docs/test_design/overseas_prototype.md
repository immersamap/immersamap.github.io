# 海外の空中写真 試作 テスト設計

- 対象: `overseas-test.html`（設計: [`docs/design/overseas_prototype.md`](../design/overseas_prototype.md)）
- 自動テスト: `tests/e2e/overseas_prototype_check.py`（Playwright・Chromium）
- 実行: `.venv/bin/python tests/e2e/overseas_prototype_check.py --shots docs/test_results/<日付>_overseas`
- 配信元に実際につなぐ（モックにしないのは、**本当に重なるか・本当に読めるか**を見るのが試作の目的だから）。
  異常系だけ `page.route` で障害を注入する

## 正常系

| ID | 観点 | 確かめること |
|---|---|---|
| N1 | 起動 | 日本・A・最新で始まる。日本の年代は9つ |
| N2 | 日本の写真 | 1945〜50年・1974〜78年のタイルが失敗なく読める |
| N3 | スイス | チューリッヒでスイスに切り替わる。年代は100。1946年が読める。写真がある時はお知らせを出さない |
| N4 | フランス | パリでフランスに切り替わる（1950〜65年・最新の2つ）。1950〜65年が読める。出典に IGN |
| N5 | B 年代でそろえる | 11区切り。フランスは 1950・60・2020年代だけ。A→B で近い年を選び直す。写真の無い年代では写真を外してお知らせ。スイスは全年代あり（1940年代＝1949年）。日本は 2000・2010年代が空く |
| N6 | 濃さ | 30% にすると写真の層の不透明度が 0.3、表示も 30% |
| N7 | 白いタイル | 1926年のチューリッヒで、白いタイルを「写真なし」と数え、隠し、お知らせを出す。1960年に戻すと消える |
| N | 全体 | スクリプトエラーが出ない |

## 異常系

| ID | 観点 | 障害の作り方 | 確かめること |
|---|---|---|---|
| E1 | 対象外の国 | 地図をニューヨークへ動かす | 写真を出さない・案内を出す・スライダーを止める。パリへ戻ると写真が出る |
| E2 | 配信元が全部失敗 | `wmts.geo.admin.ch` への通信をすべて中断 | **注入が効いたこと**（成功0・失敗>0）。「読み込めませんでした」と出す。パリへ移動できる（画面が止まらない） |
| E3 | 一部だけ失敗 | `data.geopf.fr` への通信を1つおきに 404 | 注入が効いたこと（成功>0・失敗>0）。お知らせは出さない |
| E4 | スマホの幅 | 390×844 | 横にはみ出さない。操作板が画面に収まる |
