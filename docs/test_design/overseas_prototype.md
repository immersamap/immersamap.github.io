# 海外の空中写真 試作 テスト設計

- 対象: `overseas-test.html`（設計: [`docs/design/overseas_prototype.md`](../design/overseas_prototype.md)）
- 自動テスト: `tests/e2e/overseas_prototype_check.py`（Playwright・Chromium）
- 実行: `.venv/bin/python tests/e2e/overseas_prototype_check.py --shots docs/test_results/<日付>_overseas`
- 写真のタイルは**表示中の分が読み終わるまで**待ってから判定・撮影する（遅い WMS で読みかけの画面写真にしない）
- 配信元に実際につなぐ（モックにしないのは、**本当に重なるか・本当に読めるか**を見るのが試作の目的だから）。
  異常系だけ `page.route` で障害を注入する

## 言葉（日本語・英語）

| ID | 観点 | 確かめること |
|---|---|---|
| L1 | 英語のブラウザで開く | `locale=en-US` で英語になる（`<html lang="en">`・題名・場所・「Latest」）。画面（操作板・濃さ）に日本語が残っていない（言葉のボタンの「日本語」は除く）。言葉のボタンは「日本語」。「Opacity」が濃さの枠からはみ出さない |
| L2 | 英語で操作する | 古地図の切り替え（Photos／Old maps）と「Old maps of Spain」も英語。一覧の都市も英語（Zurich でスイスへ）。写真が無いお知らせ・ルール地方の出典の言葉も英語。年は `1946`・`1973–1986` の形。移動しても日本語が残らない |
| L3 | 英語で対象外の場所 | お知らせと場所のボタンが英語（This prototype covers only / Outside coverage） |
| L4 | 切り替え | 「日本語」を押すと日本語になる。場所と年はそのままで、写真を読み直さない（層は1つ）。アドレスに `lang=ja` を残す（`file://` で残せなくても止まらない） |
| L5 | アドレスの指定（異常系を含む） | 日本語のブラウザでも `?lang=en` なら英語。`?lang=xx` はブラウザの言葉になり、エラーにならない |
| L6 | 長い国名（スマホ） | 390px・360px の日本語・英語で「オーストリア・ウィーン／Austria · Vienna」でも、場所のボタンが言葉のボタンにかからず、横にはみ出さず、国名が切れない |
| L | 全体 | 英語の画面でスクリプトエラーが出ない |
